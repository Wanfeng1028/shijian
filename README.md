# 史鉴 · 高中历史 AI 教学智能体

面向高一至高三学生的 AI 历史教师，以人教版高中历史教材与《普通高中历史课程标准（2017年版2020年修订）》为依据，用史料引导学生发现问题。

## 功能

- **首页三入口**
  - 史料阅读
  - 史料辨析
  - 历史解释

- **六阶段探究流程**
  1. 阅读史料
  2. 提取信息
  3. 发现问题
  4. 辨析证据
  5. 建立联系
  6. 形成解释

- **教材适配**
  - 适配五册人教版高中历史教材：
    - 《中外历史纲要》上册
    - 《中外历史纲要》下册
    - 《选择性必修 1 国家制度与社会治理》
    - 《选择性必修 2 经济与社会生活》
    - 《选择性必修 3 文化交流与传播》
  - 支持年级与学期进度档案，数据保存在浏览器 `localStorage` 中。

- **学习反馈评价**
  - 从四个维度进行 1—5 分评价：
    - 信息提取
    - 史料辨析
    - 历史联系
    - 历史解释

- **学习记录页**
  - 查看历史探究过程、反馈评价与学习轨迹。

- **图片与文档上传**
  - 支持上传图片和文档材料，辅助学生进行史料阅读与分析。

## 技术

- **前端**
  - 纯静态站，无构建步骤。
  - 页面：
    - `index.html`
    - `chat.html`
    - `records.html`
  - 样式：
    - `css/styles.css`
  - 脚本：
    - `js/app.js`
    - `js/chat.js`
    - `js/records.js`

- **后端**
  - Cloudflare Pages Function：
    - `functions/api/chat.js`
    - `POST /api/chat`
  - 经 OpenRouter 调用免费模型：
    - 主模型：`baidu/ernie-5.5-flash-preview:free`
    - 备用模型：`inclusionai/ling-3.2-flash:free`
    - 视觉模型：`nvidia/nemotron-3.5-super-vl:free`
  - 每 IP 每分钟限流 10 次。

- **部署**
  - 部署在 Cloudflare Pages。

## 本地预览

在仓库根目录使用任意静态服务器启动，例如：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

注意：`/api/chat` 需要部署到 Cloudflare Pages 后配置 `OPENROUTER_API_KEY` 才能使用。未配置时，前端会明确显示「后端未配置」。

## 环境变量

| 变量名 | 说明 | 要求 |
| --- | --- | --- |
| `OPENROUTER_API_KEY` | OpenRouter API Key | 必填；仅服务端使用；绝不进入前端代码与仓库 |

## 数据与隐私

- 学习档案与学习记录只保存在当前浏览器的 `localStorage` 中。
- 清除浏览器数据会导致学习档案与学习记录丢失。
- 更换设备后数据不会自动同步。
- 不上传个人信息到自有服务器；对话内容仅发送给模型服务商用于生成回答。

## 教学说明

- 史鉴不直接给结论，而是通过追问与史料引导学生发现问题、展开论证。
- 不编造史料与出处；无法确认的信息会明确说明。
- 史料原文、历史事实与 AI 推论会在回答中明确区分。
- 对争议问题，呈现不同解释及其支撑证据。
